# Steerlo

Beginner-friendly Next.js starter app using App Router, TypeScript, and Tailwind CSS.

## Features

- Authentication with Supabase (`/login`, `/signup`, logout)
- Simple dashboard (`/dashboard`)
- AI-style essay brainstorming demo (`/brainstorm`)

## Supabase Setup

1. In Supabase, create a project.
2. In Supabase dashboard, go to `Project Settings -> API`.
3. Copy:
   - Project URL
   - `anon` public key
4. Create `.env.local` in the project root and add:

```bash
NEXT_PUBLIC_SUPABASE_URL=your-project-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

You can copy from `.env.local.example` and replace the values.

## AI Setup

The essay generator uses Groq from the server route at `/api/essay`.

Add these values to `.env.local`:

```bash
GROQ_API_KEY=your-groq-api-key
GROQ_MODEL=llama-3.3-70b-versatile
```

`GROQ_MODEL` is optional. If you omit it, the app uses `llama-3.3-70b-versatile`.

## Contact Form Setup

The homepage contact modal sends messages through the API route at `/api/contact`.

For production email delivery, add these environment variables in Vercel and `.env.local`:

```bash
RESEND_API_KEY=your-resend-api-key
CONTACT_FROM_EMAIL=Steerlo <onboarding@resend.dev>
```

If `RESEND_API_KEY` is missing in development, the route uses a safe local fallback so you can verify the UI flow without sending a real email.

## Database Setup

Create a table named `essay_submissions` in Supabase for saved essay requests and AI results.

Example SQL:

```sql
create table if not exists public.essay_submissions (
  id bigint generated by default as identity primary key,
  life_experience text,
  challenge text,
  proud_of text,
  interests text,
  ideas jsonb not null,
  model text not null,
  created_at timestamptz not null default now()
);
```

The API route writes each submission and the 3 generated ideas into this table using the service role key.

## Auth Notes

- Session persistence is handled by Supabase client auth (stored in browser).
- `AuthProvider` and `useAuth` keep user state synced in the UI.
- Dashboard access is protected by middleware and a server-side user check.

## Run Locally

1. Install Node.js 20+.
2. Install dependencies:

```bash
npm install
```

3. Start development server:

```bash
npm run dev
```

Open `http://localhost:3000`.
